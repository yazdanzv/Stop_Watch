## Code guide

`Stop_Watch.py` contains the complete Tkinter interface and the `Timer` class. Its start, pause, and reset controls update the displayed elapsed time. Run `python Stop_Watch.py` in a graphical Python environment; no third-party package is imported by this script. The timer uses a background thread, so this is a small GUI exercise rather than a timing library.
